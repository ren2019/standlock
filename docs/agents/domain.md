# Domain docs

StandLock uses a single domain context. Read the root `GLOSSARY.md` and the relevant decisions in `docs/adr/` before exploring a domain topic. If either is absent, proceed with the available material.

Use the glossary's vocabulary in issues, proposals, and tests. Record agreed terminology through the domain-modeling skill as it emerges. Add ADRs when decisions are made, and call out any proposal that would reopen an existing ADR.
